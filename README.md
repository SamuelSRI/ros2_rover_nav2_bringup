# ros2_rover_nav2_bringup

ROS 2 bringup package for running Nav2 on a tracked rover.

This package provides launch and configuration files to start the Nav2 navigation stack using rover odometry, TF, and LiDAR-based local obstacle data.

It is intended to connect the rover autonomy stack to Nav2 and publish velocity commands on `/cmd_vel`, which can then be converted to left and right track commands by a lower-level controller.

## Features

* Nav2 bringup package for a tracked rover
* Uses `odom` as the global navigation frame
* Uses `base_link` as the robot base frame
* Uses filtered odometry from `/odometry/filtered`
* Uses LiDAR point cloud obstacle data from `/local_cloud_filtered`
* Publishes velocity commands on `/cmd_vel`
* Includes YAML configuration file
* Includes ROS 2 launch file
* Designed for local navigation tests before adding full global localization

## Expected rover stack

This package assumes that the following parts of the rover stack are already running:

```text
robot_state_publisher
    → static TF from base_link to sensors

localization / EKF
    → /odometry/filtered
    → TF odom -> base_link

LiDAR / mapping
    → /local_cloud_filtered

track controller
    → subscribes to /cmd_vel or converts /cmd_vel to track speed commands
```

Typical full architecture:

```text
LiDAR
  ↓
/local_cloud_filtered
  ↓
Nav2 costmaps
  ↓
Nav2 planner / controller
  ↓
/cmd_vel
  ↓
cmd_vel_to_tracks
  ↓
/vesc/track_speed_cmd
  ↓
VESC motor controllers
```

## Topics

### Subscribed topics

```text
/odometry/filtered
```

Type:

```text
nav_msgs/msg/Odometry
```

Filtered rover odometry.

```text
/tf
/tf_static
```

Robot transform tree.

```text
/local_cloud_filtered
```

Type:

```text
sensor_msgs/msg/PointCloud2
```

Filtered LiDAR point cloud used by Nav2 obstacle layers.

### Published topics

```text
/cmd_vel
```

Type:

```text
geometry_msgs/msg/Twist
```

Velocity command generated by Nav2.

Depending on the rest of the rover stack, `/cmd_vel` can be consumed directly or converted into track speed commands.

## Frames

Default frames used by this package:

```text
global_frame: odom
robot_base_frame: base_link
odom_topic: /odometry/filtered
```

This package is currently configured for local navigation using `odom` as the global frame.

A future global navigation setup can add a `map -> odom` transform using GPS, SLAM, or another global localization source.

## Configuration

Main configuration file:

```text
config/nav2_params.yaml
```

Important parameters include:

| Parameter                         | Description                                   |
| --------------------------------- | --------------------------------------------- |
| `global_frame`                    | Global frame used by Nav2, currently `odom`   |
| `robot_base_frame`                | Rover base frame, usually `base_link`         |
| `odom_topic`                      | Filtered odometry topic                       |
| `robot_radius`                    | Approximate robot radius used by costmaps     |
| `max_vel_x`                       | Maximum forward velocity                      |
| `max_vel_theta`                   | Maximum angular velocity                      |
| `local_costmap.width`             | Width of the local costmap                    |
| `local_costmap.height`            | Height of the local costmap                   |
| `obstacle_layer.pointcloud.topic` | PointCloud2 topic used for obstacle detection |

## Dependencies

Install Nav2 if it is not already installed.

For ROS 2 Lyrical:

```bash
sudo apt update
sudo apt install ros-lyrical-navigation2 ros-lyrical-nav2-bringup
```

For a generic ROS 2 distribution:

```bash
sudo apt update
sudo apt install ros-$ROS_DISTRO-navigation2 ros-$ROS_DISTRO-nav2-bringup
```

## Build

From your ROS 2 workspace:

```bash
cd ~/ros2_ws
source /opt/ros/lyrical/setup.bash
colcon build --packages-select ros2_rover_nav2_bringup
source install/setup.bash
```

Or with `$ROS_DISTRO`:

```bash
cd ~/ros2_ws
source /opt/ros/$ROS_DISTRO/setup.bash
colcon build --packages-select ros2_rover_nav2_bringup
source install/setup.bash
```

## Run

Launch Nav2:

```bash
ros2 launch ros2_rover_nav2_bringup nav2_bringup.launch.py
```

## Testing

Before launching this package, verify that odometry is available:

```bash
ros2 topic echo /odometry/filtered
```

Verify that TF is available:

```bash
ros2 run tf2_ros tf2_echo odom base_link
```

Verify that the LiDAR obstacle cloud is available:

```bash
ros2 topic hz /local_cloud_filtered
```

After launching Nav2, check for costmap and command topics:

```bash
ros2 topic list | grep costmap
ros2 topic list | grep cmd_vel
```

## Safety note

For the first tests, keep the rover lifted, disable motor power, or limit the motor controller output.

Nav2 can publish velocity commands on `/cmd_vel` as soon as a goal is sent.

## Current limitations

This package currently provides local navigation bringup only.

It does not yet provide:

* `map -> odom` global localization
* GPS waypoint navigation
* SLAM-based global mapping
* Mission-level autonomy
* Recovery behavior tuning for outdoor terrain
